# 30-Day Java & Spring Mastery Plan — Prompt

## Goal

Design a **30-day, project-based learning plan** to master **Java** and the **Spring framework** to a level equivalent to a **senior engineer**. Each day's project should take roughly **1 hour** to complete. 

# Scope
- Each project should include and teach one concept from internal database design or distributed systems.
- Each project should teach one common library or tool used in java ecosystem.

## Deliverables

1. An overall **index.html** that sequences the 30 days so concepts build on each other.
2. For **each day**, create a directory named `dayX/` (e.g., `day1/`, `day2/`, …) containing a `CHALLENGE.md` file.

## `CHALLENGE.md` Format

Each `CHALLENGE.md` must begin with a header block summarizing:

- **Java Topic Learning** — the key java concepts and skills covered.
- **DB or Distributed Systems Topic Learning** — the database or distributed system topic covered.
- **Common Library or Tool Learning** — the common library or tool covered.
- **Difficulty** — a clear rating of how hard the challenge is.

After the header, provide **detailed, step-by-step instructions** explaining how to complete the project, with enough depth to follow without external hand-holding. Include a lot of details here and explain important concepts that I need to know.

## `index.html` Format

The list of days is on the left side and when clicked the MD file is opened automatically and the content is shown. The content should be loaded dynamically.
The page style should look similar to leetcode and each day can be marked as done by the user.


## Instruction

Think hard about sequencing, depth, and topic coverage before producing the plan. Fanout each day to a subagent.
